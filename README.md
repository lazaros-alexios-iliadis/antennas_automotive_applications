# Automotive Radar Antenna Designs (77–81 GHz)

This repository contains two **Ansys HFSS** antenna design projects developed for **automotive radar applications** operating in the **77–81 GHz mmWave band**, with a central frequency of **79 GHz**.

The designs target use cases relevant to **advanced driver-assistance systems (ADAS)** and **autonomous driving**, where wide bandwidth, stable radiation characteristics, and compact form factors are critical.

---

## Included Designs

### 1. Aperture-Coupled Bowtie Patch Antenna
- Wideband operation covering the full 77–81 GHz automotive radar band
- Aperture-coupled feeding for improved bandwidth and isolation
- Designed and optimized using full-wave electromagnetic simulations in HFSS

### 2. Wideband Aperture-Coupled Antenna Array
- Array configuration for increased gain and improved angular resolution
- Optimized for automotive radar front-end integration
- Emphasis on bandwidth, radiation stability, and manufacturability

---

## Simulation Environment

- **Software:** Ansys HFSS
- **Frequency Band:** 77–81 GHz (mmWave)
- **Central Frequency:** 79 GHz
- **Analysis Type:** Full-wave 3D electromagnetic simulation

Each HFSS project file contains the complete geometry, material definitions, excitation setup, and simulation configuration required to reproduce the reported results.
